Slices Dinamik massiv — Go-da ən çox işlənən kolleksiya

başlanğıc 4 dəq #09 / 84 vizual

Slice — eyni tipli elementlərin ardıcıllığıdır. Massivdən (arrays) fərqi: ölçüsü sabit deyil, lazım olduqca böyüyür. Praktikada Go-da massiv əvəzinə demək olar ki, həmişə slice işlədilir.

1

Boş slice

[]string — “string-lərdən ibarət slice”. Mötərizənin içi boşdur: ölçü göstərilmir.

Yeni elan olunmuş slice boşdur: uzunluğu 0, dəyəri nil.


          

          
2
            
make ilə hazır ölçü

            
make([]string, 3) 3 elementli slice yaradır. Elementlər sıfır dəyərlə dolur — string üçün "".

            
Elementə indekslə müraciət edilir: s[0]. Saymaq 0-dan başlayır.

            

          

          
3
            
append ilə əlavə

            
append sona element əlavə edir və yeni slice qaytarır. Yer çatmayanda Go daha böyük massiv ayırır.

            
Diqqət: nəticəni geri yazın — s = append(s, ...). Yalnız append(s, "d") yazsanız, s dəyişməz.

            

          

          
4
            
Kəsik götürmək s[a:b]

            
a-dan başlayır, b-yə qədər gedir — b daxil deyil. s[1:3] → 1-ci və 2-ci elementlər.

            
Bilgi: kəsik yeni yaddaş ayırmır — orijinal slice ilə eyni elementləri “görür”.

            

          

          
5
            
Qısa yazılış

            
Elementlər əvvəlcədən məlumdursa, slice-ı birbaşa dəyərlərlə yaradın. := tipi özü təyin edir.
