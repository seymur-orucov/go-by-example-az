İlk proqramımız ənənəyə görə ekrana salam yazır. Kod qısadır, amma hər Go proqramının quruluşunu göstərir.

## Paket {#package}

Hər Go faylı `package` ilə başlayır. İşə salınan proqramın paketi həmişə `main` olur.

## Import {#import}

`import` başqa paketləri qoşur. `fmt` standart kitabxananın paketidir: mətni çap etmək və formatlamaq üçündür.

## main funksiyası {#main}

Proqram `main` funksiyasından başlayır. `fmt.Println` mətni çap edir və sonuna yeni sətir əlavə edir.

Proqramı işə salmaq üçün terminalda `go run main.go` yazın.
